# Celsius-to-Fahrenheit-Calculator
A Celsius to Fahrenheit Calculator created using HTML, Bootstrap, and JavaScript is a simple web-based tool that allows users to convert temperatures from degrees Celsius to degrees Fahrenheit with ease.

🔧 Features & Description:

HTML is used to create the structure of the calculator, including input fields, labels, buttons, and result display.

Bootstrap provides responsive design and styling, ensuring the calculator looks clean and works well on all device sizes. Bootstrap classes are used for layout, spacing, buttons, and form styling.

JavaScript adds the core functionality: when a user enters a Celsius value and clicks the Convert button, JavaScript reads the input, performs the conversion using the formula F = (C × 9/5) + 32, and displays the result in Fahrenheit.

🖥️ User Interface:

A title like "Celsius to Fahrenheit Converter"

An input box labeled "Enter Celsius"

A Convert button styled using Bootstrap

A display area showing the result in Fahrenheit

✅ Advantages:

Fast and lightweight – no need for page reloads

Mobile-friendly – thanks to Bootstrap responsiveness

Educational – useful for students and anyone needing quick temperature conversions
